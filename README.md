# Codex 大肥鱼桌宠｜codexの大肥鱼替身 🐟

**简体中文** · [English](README.en.md) · [日本語](README.ja.md)

**Codex 大肥鱼**是一个为 Codex 原生 Pets 制作的原创 V2 自定义宠物。安装后可在 Codex 的 Pets 设置中选择她。项目由社区制作，并非 OpenAI 官方产品。

大肥鱼的角色设定、主视觉图和宠物图集均为本项目原创。图集包含 9 类动画状态和 16 向视线方向。

## 一句话让 Codex 安装

在 **Mac 上的 Codex 本地聊天**中复制并发送：

```text
请帮我把“codexの大肥鱼替身”添加为 Codex 原生 Pets 自定义宠物：
https://github.com/EthanCai330/codex-no-da-fei-yu-ti-shen

请阅读仓库 README 中的官方 Pets 安装说明，并将宠物配置和 V2 图集安装到 Codex 支持的自定义宠物目录。
保留我现有的官方 Pets、当前选择和其他设置，不要修改、覆盖或自动切换它们。
完成后告诉我是否需要重启 Codex，以及如何在 Pets 设置中手动选择“Codex 大肥鱼”。
```

## 官方 Pets 安装

将 [V2 宠物图集](docs/images/big-fat-fish-spritesheet.webp) 与 [宠物配置](docs/images/pet.json) 放入 Codex 的自定义宠物目录：

```text
~/.codex/pets/codex-big-fat-fish/
├── pet.json
└── spritesheet.webp
```

将图集命名为 `spritesheet.webp`。然后重启 Codex，在 Pets 设置中选择“Codex 大肥鱼”。添加宠物不会替换已有宠物；更新同 ID 的图集后，完全退出并重新打开 Codex，以刷新缓存。
